# 🎬 TBD Movies v0.12.6

A modern, fast, and local-first desktop media library for Windows built with **WinUI 3 & .NET 10**.

### ✨ What's New & Highlights
• **⚡ Instant Library Loading**: Zero flicker and sub-5ms loading for movies and TV shows from local SQLite WAL.
• **🔄 Two-Way Trakt Sync**: Unified custom lists, offline favorites queue, and cloud synchronization (Database Schema v24).
• **🎬 Trakt Scrobbler Full Lifecycle & 80% Parity**: Seamless Start, Pause, and reliable Stop on player exit/app shutdown, unified at 80% watched completion.
• **🖼️ Smart Poster Cache**: True LRU cache with automatic 256MB disk pruning and instant offline browsing.
• **🛡️ Hardened Security**: Token protection in Windows Credential Manager, single-instance mutex, and 26 security patches.
• **🌍 Full Arabic & English Support**: Complete RTL/LTR layout parity with Fluent Design.
• **🧪 Clean Build**: Zero compiler warnings and 1,470 / 1,470 passing automated tests (100% Green CI).
